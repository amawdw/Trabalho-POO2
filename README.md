README
Participantes: Arthur Monte, Amanda Ribeiro
Este trabalho de Programação Orientada a Objetos tem como objetivo desenvolver um sistema em Java que automatize o controle de estudantes, disciplinas e notas de uma escola de ensino médio. A proposta é aplicar o uso das coleções da linguagem, como List, Set e Map, para armazenar, organizar e manipular dados de forma eficiente. O projeto busca mostrar domínio sobre a escolha das estruturas adequadas, a criação de métodos organizados e a geração de relatórios simples em memória.
O sistema deve permitir gerenciar uma lista de estudantes, garantindo operações como inclusão, remoção, busca e ordenação. Além disso, deve controlar disciplinas únicas, evitando duplicatas, e associar cada estudante às suas matrículas e notas. Também é necessário que o programa calcule médias individuais e por disciplina, identifique alunos aprovados e liste informações gerais de desempenho.
Na primeira parte, chamada de Parte A, o foco está na manipulação de listas. O aluno deve implementar métodos que adicionem, removam, busquem e ordenem estudantes usando implementações como ArrayList ou LinkedList. A saída esperada inclui a exibição da lista original de estudantes e a versão ordenada alfabeticamente.
A Parte B aborda o uso de conjuntos (Set), com o objetivo de impedir que existam disciplinas duplicadas. São exigidos métodos para adicionar e remover disciplinas, verificar se uma disciplina existe e obter todas em ordem de inserção ou ordenadas, utilizando estruturas como LinkedHashSet ou TreeSet.
Na Parte C, o projeto trabalha com mapas (Map), relacionando estudantes às suas disciplinas e notas. Devem ser criados métodos para adicionar e remover matrículas, consultar notas, calcular médias por aluno e por disciplina, além de gerar um ranking dos estudantes com as maiores médias. O uso de HashMap é recomendado, mas o estudante pode justificar outra escolha caso necessário.
A Parte D integra todas as funcionalidades em um programa principal, o Main. Ele deve carregar os dados fornecidos, exibir as listas de estudantes e disciplinas, apresentar as notas e médias de cada aluno e mostrar os resultados solicitados, como alunos com média igual ou superior a 8, disciplinas com média abaixo de 6 e possíveis duplicatas detectadas na importação. Também há uma tarefa extra opcional, que permite buscar estudantes por parte do nome e exibir disciplinas em que obtiveram notas acima da média da turma.
As classes sugeridas para a implementação são Estudante, com id e nome; Disciplina, com código e nome; Matricula, que relaciona disciplina e nota; ListaEstudantes, responsável pelos métodos da parte A; CadastroDisciplinas, que cuida da parte B; e HistoricoNotas, que implementa os métodos da parte C. Todas elas são integradas pelo programa principal.
O projeto inclui ainda um conjunto de dados de exemplo com cinco estudantes (Ana, Bruno, Carla, Diego e Elisa), quatro disciplinas (Matemática, Programação, Banco de Dados e Educação Física) e um conjunto de notas associadas a cada aluno. Esses dados devem ser usados para testar e validar as funcionalidades do sistema.
Por fim, o trabalho sugere uma extensão criativa: adicionar às classes objetos complementares, como pokémons ou receitas de bolo, mostrando que os estudantes também possuem outras informações associadas a eles. Essa parte tem como objetivo incentivar o uso de composição de objetos e a personalização do sistema.
Em resumo, o trabalho propõe um exercício completo de manipulação de coleções em Java, exigindo organização, clareza no código, domínio de estruturas de dados e integração entre diferentes tipos de coleções para resolver um problema prático de forma eficiente.
