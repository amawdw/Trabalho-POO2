O trabalho foi desenvolvido por Amanda Passos Ribeiro e Arthur Bandeira Miranda Monte com o objetivo de aplicar os conceitos de Programação Orientada a Objetos utilizando coleções em Java. O programa tem como finalidade automatizar o controle de estudantes, disciplinas e notas de uma escola de ensino médio, permitindo o gerenciamento de informações de forma eficiente e organizada. Ele possibilita cadastrar, remover, buscar e ordenar estudantes, registrar disciplinas sem duplicação, associar alunos às suas respectivas notas e gerar relatórios contendo médias individuais, médias por disciplina, alunos aprovados e outros resultados gerais.

A escolha das coleções foi feita de acordo com as características de cada necessidade do sistema. Para a lista de estudantes, utilizou-se a estrutura List, mais especificamente a implementação ArrayList, pois ela permite acesso rápido por índice e é ideal para armazenar elementos em ordem de inserção, facilitando operações de ordenação e busca. No caso das disciplinas, foi usada a coleção Set, com a implementação LinkedHashSet, garantindo que não existam duplicatas e mantendo a ordem de inserção, o que facilita a exibição dos dados na mesma sequência em que foram cadastrados. Já para a associação entre estudantes, disciplinas e notas, foi empregada a coleção Map, com a implementação HashMap, pois ela permite relacionar uma chave (o identificador do estudante) a um conjunto de valores (as matrículas e notas), possibilitando acesso rápido e eficiente às informações e facilitando o cálculo das médias.

Para executar o programa, é necessário ter o JDK instalado e abrir o projeto em uma IDE como IntelliJ IDEA ou Eclipse. Após compilar os arquivos .java, o programa principal pode ser executado por meio da classe Main, que carrega os dados de exemplo e exibe os relatórios no console. Ao final da execução, o sistema gera automaticamente o arquivo output.txt, contendo a saída formatada com todas as informações do relatório, incluindo a lista de estudantes, disciplinas, médias, alunos aprovados e ranking dos melhores desempenhos.

Durante o desenvolvimento, o principal desafio encontrado foi a integração das três coleções em um mesmo fluxo de execução, garantindo que as operações realizadas em uma estrutura refletissem corretamente nas demais. Também foi necessário planejar bem os métodos de cálculo de média e as relações entre classes para evitar redundância de dados. Outro ponto desafiador foi a manipulação dos dados de forma genérica e reutilizável, respeitando os princípios da orientação a objetos e mantendo o código legível e modular.

Em síntese, o projeto demonstrou como as coleções do Java podem ser aplicadas em um contexto real para resolver problemas de gerenciamento de dados, reforçando o entendimento sobre estruturas de armazenamento, relacionamentos entre objetos e boas práticas de programação.
